# Omukuumi CLI

**Omukuumi** is a Kinyarwanda-first AI coding assistant for the terminal.

## Quick Start

```bash
# Install via npm (after publish)
npm install -g omukuumi
omukuumi

# Or use the installer
curl -fsSL https://console.omukuumi.org/install.sh | bash
```

## Documentation

- **English**: [README.en.md](README.en.md)
- **Kinyarwanda**: [README.rw.md](README.rw.md)

## Install

```bash
# npm (after publish)
npm install -g omukuumi

# Or installer
curl -fsSL https://console.omukuumi.org/install.sh | bash
```

## Usage

```bash
omukuumi                    # Interactive mode
omukuumi -p "Explain this" # One-shot
omukuumi @README.md "Summarize"
```
